🌐 Location Lab

A simple Python + Flask location reporting tool for Termux.

✨ Features

- 🌍 Browser-based location permission
- 📍 Address lookup using OpenStreetMap
- 🖥️ Location report displayed in Termux
- 🔒 Localhost-only web server

📥 Installation
```bash
git clone https://github.com/UG-ALOK/Location-hack.git
```
```bash
cd Location-hack
``` 
```bash
chmod +x install.sh
./install.sh
```
Replace the repository URL and folder name with your actual Git repository details.

🚀 Run
```bash
python 'Location Tracker.py'
```
